# LibrarySystem Web Version - 使用者 + 管理者完整版

這份專案按照原本使用者端的格式製作，維持純靜態網頁架構：

- `index.html`
- `admin.html`
- `styles.css`
- `app.js`
- `admin.js`
- `localStorage` 暫存資料庫

## 原本使用者端功能

- 使用者註冊 / 登入
- 使用者首頁
- 館藏查詢
- 查看書本資訊
- 查看書籍借閱紀錄
- 借書
- 個人借閱紀錄
- 還書

## 新增管理者端功能

- 管理者登入
- 管理者首頁 / 統計儀表板
- 書籍管理
  - 查詢書籍
  - 新增書籍
  - 下架書籍
  - 恢復書籍
- 使用者管理
  - 查看所有使用者
  - 停權使用者
  - 復權使用者
- 借還紀錄管理
  - 查看全部紀錄
  - 依狀態篩選
  - 自動更新逾期狀態
- 資料庫管理
  - 查看 localStorage 資料筆數
  - 匯出 JSON 資料庫
  - 重設示範資料

## 測試帳號

### 使用者

```text
S001 / 1234
S002 / 1234
```

### 管理者

```text
A001 / admin123
```

## 執行方式

直接用瀏覽器打開：

```text
index.html
```

首頁會出現「一般使用者」與「管理者」。

也可以直接打開：

```text
admin.html
```

進入管理者登入頁。

## 資料庫說明

目前版本是靜態網頁，所以資料庫使用瀏覽器的 `localStorage` 暫存。

Storage Key：

```text
library-system-state-v1
```

所有使用者端與管理者端會共用同一份 localStorage 資料。
